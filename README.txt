ГОТОВЫЕ САЙТЫ — каталог (SITE MARKET 3)

ЧТО ЭТО
Витрина из 12 проектов в дизайне «Не шаблон» (мятный ретро-стиль), но с рабочей логикой
старого Site Market: реальные скриншоты ПК + мобильный, живой сайт в эмуляторе устройства,
переключатель ПК/мобильная, кнопка «Перейти на сайт», блок «Подойдёт», фильтры и заявка
с автоподстановкой выбранного проекта.
Кнопка «Как это работает» рядом с «Заказать сайт» раскрывает описание гармошкой вниз;
внутри свои кнопки «Заказать сайт» и «Свернуть». Текст описания: source/src/i18n.ts, howParagraphs.

ЗАПУСК
Открыть index.html в современном браузере (двойной клик) — сборка не нужна.
Если браузер не открывает локальный файл, поднять локальный сервер из этой папки:
  python -m http.server 8080
и перейти на http://localhost:8080

ЯЗЫКИ
Одна страница, переключатель UA / EN / RU в шапке. По умолчанию русский; выбор
запоминается в браузере. Если браузер украинский или английский, при первом заходе
сайт откроется на нём — это отключается в source/src/main.tsx (функция detectLang).

ЭМУЛЯТОР
Нажатие на большой макет открывает ПК-версию, на узкий — мобильную. Внутри — живой сайт
во фрейме; сверху вниз страница прокручивается. Пока сайт грузится, показывается скриншот
с плашкой «Загружаем сайт…», затем сайт проявляется. Если сайт не открылся за 15 секунд,
остаётся скриншот с пояснением и ссылкой.

303 SCREEN BREAK TIMER
Этот сайт отдаёт X-Frame-Options: DENY и физически не может открыться во фрейме,
поэтому для него всегда показывается скриншот с кнопкой «Перейти на сайт».

ЗАЯВКА
Форма собирает данные и показывает черновик («Не отправлена: канал приёма ещё не подключён»).
Реальной отправки нет — её нужно подключать отдельно (Telegram-бот, почта или сервис форм).

ДАННЫЕ
Все 12 проектов: source/src/projects.json
 (id, title, category, url, shots, description и fit на ru/uk/en, embeddable).
Категории: shop, corporate, landing, services, blog — порядок и подписи в source/src/i18n.ts.
Скриншоты: assets/shots/<id>-pc.webp и <id>-mobile.webp.
Шрифты: assets/fonts (Oswald, Unbounded, Inter, IBM Plex Mono), лицензии рядом.

СБОРКА
В папке source/: npm install, затем npm run build.
Команда обновляет site.js и site.css в корне. Зависимости уже установлены.

СОСТАВ
index.html, site.js, site.css, fonts.css — готовая сборка.
source/src — исходники React (экраны, данные, переводы, стили).
assets — шрифты и скриншоты.
